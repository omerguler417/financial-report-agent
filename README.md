We believe finance students and individual investors will save time and better understand a company’s performance through an agent that analyses its financial reports. The agent will use the LLM’s strengths in summarising complex text and extracting information to explain results and identify inputs for user-selected financial indicators. This approach breaks if the model invents figures, confuses reporting periods or units, or performs calculations incorrectly. We will mitigate these risks by citing source passages, calculating indicators using Python, and flagging missing or ambiguous information. We would know it works if at least 95% of extracted figures across ten sample reports match a manually verified benchmark, calculated indicators match independently computed results within a predefined rounding tolerance, and users complete a standard analysis task faster than manually.
